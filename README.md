## 🚀 Featured Project

### 📦 Nassau Candy Distributor — Profitability Analysis
> Exploratory data analysis and interactive Streamlit dashboard for product line profitability and margin performance at Nassau Candy Distributor.

| | |
|---|---|
| 🔴 **Live Dashboard** | [ncd-profitability-dashboard.streamlit.app](https://ncd-profitability-dashboard.streamlit.app/) |
| 📄 **Published Paper** | [AIJFR Volume 7, Issue 3 (May–June 2026)](https://www.aijfr.com/papers/2026/3/5984.pdf) |
| 💻 **GitHub Repo** | [Nassau-Candy-Profitability-Analysis](https://github.com/GeethaS87/Nassau-Candy-Profitability-Analysis) |

**Key findings:**
- Chocolate division drives 92.88% of revenue with a 67.45% average gross margin
- 5 of 15 products generate 80% of total revenue — significant concentration risk
- Kazookles identified as highest-priority cost renegotiation candidate (92.31% cost ratio)
- Sugar division underutilised — 66.61% gross margin but near-zero revenue ($427.48)
